# Баг-патруль

**Найдите сбой. Исправьте код. Доставьте пакет.**

Обучающий 3D-квест о роботе-курьере в цифровом городе. В каждом отделе что-то сломалось: бот повторяет приветствие, сервер перегревается, охрана пропускает посторонних. Найдите причину в коротком JavaScript, проверьте исправление и верните город к жизни.

**[Скачать игру](https://github.com/kryukovilya/bug-patrol/releases/latest)**

## Что внутри

- Пять расследований: переменные, условия, логика, циклы и ожидание ответа.
- Настоящий редактор JavaScript и проверка результата на разных примерах.
- Быстрые замены кода и подсказки Кваксильды, если нужна помощь.
- Роботы с характером, IT-шутки и заметные изменения в 3D-комнатах после ремонта.
- Финальный ребус, музыка, звуки и управление с телефона.

## Как играть

Поговорите с героем, повторите сбой и изучите код. Исправьте причину, запустите проверку и примените исправление в комнате: перезапустите бота или включите охлаждение. За каждый ремонт вы получите фрагмент адреса. Соберите их в финале, чтобы курьер доставил пакет.

Кваксильда подскажет следующий шаг и поможет с кодом. Прогресс сохраняется автоматически.

## Запуск

Скачайте `bug-patrol-v2.6.1-game.zip` в [разделе релизов](https://github.com/kryukovilya/bug-patrol/releases/latest), распакуйте и откройте `index.html` в современном браузере.

Для игры по ссылке с телефона разместите содержимое архива на статическом HTTPS-сервере.
